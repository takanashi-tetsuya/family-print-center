需要登入

管理打印機需要管理員密碼。一般家人列印不需要登入。

第一次使用？初始密碼保存在伺服器上。在 OpenWrt 的終端機執行下面指令即可看到： docker exec family-print-center cat /var/lib/family-print-center/admin-initial-password

自動檢測

輸入 IP 位址

IP 位址通常可以在打印機面板的「網路」設定，或列印出來的「網路設定頁」上找到。

手動指定連線方式（進階）

留空會使用常見設定。

只有打印機說明書另有指定時才需要填寫。

上傳驅動檔

清單裡找不到你的型號時，可以上傳廠商提供的 PostScript 驅動檔（副檔名 .ppd）。需要另外安裝程式的驅動，無法用上傳的方式加入。

打印任務

所有人送出的打印任務，最新的在最上面。卡住的任務可以在這裡取消。

字體

Word、Excel、PowerPoint 文件用到伺服器沒有的字體時，會改用其他字體，排版可能和原本略有不同。

最近缺少的字體

家人最近上傳的文件用到、伺服器上沒有的字體。加入同名字體後，它就會從這裡消失。

加入字體

可以從自己的 Windows 電腦複製（C:\Windows\Fonts），支援 .ttf、.otf、.ttc，每個檔案最多 64 MB。加入後立即生效，不用重新啟動；打印頁上已放入的文件列印時也會使用，但要重新放入才會看到新的預覽。商業字體只限家中自用。

系統

你正在使用系統產生的初始密碼。請先設定一個新密碼，之後才能管理打印機。

更改管理員密碼

至少 8 個字元。改密碼後，其他已登入的瀏覽器會被登出。

忘記密碼

在 OpenWrt 的終端機刪除密碼檔並重新啟動，系統會產生新的初始密碼：

docker exec family-print-center rm /var/lib/family-print-center/admin.json
docker restart family-print-center
